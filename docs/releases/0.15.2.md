# Atlas Agent 0.15.2

Choose your interface language with `/language`: English, Turkish, German,
French, Italian, or Arabic. The selection is saved for subsequent launches.

## Changes

- A searchable language picker with native language names, the current
  selection, and retry support when saving fails.
- Translated built-in command descriptions, menus, keyboard hints, onboarding,
  authentication screens, permissions, questions, and notifications.
- Localized session lists, relative timestamps, job and agent panels, model
  settings, tool output labels, and workflow controls and validation messages.
- Language changes refresh the current interface without replacing message
  content, editor drafts, command identifiers, paths, or workflow control IDs.
- Localized exit messages retain the original session resume command.
- Configure the language through `option ui language tr` in atlasrc or
  `options.tui.language` in JSON. Unsupported values are rejected; English is
  the default and fallback for untranslated text.
- Portable browser and isolation test fixtures, and a direct terminal
  dependency declaration carried forward from the fixes after v0.15.1.

Arabic glyph shaping and direction depend on the terminal. The interface
language setting does not change the language of model responses.

## Validation

The full repository test suite passed locally. After the final exit-message
change, the affected i18n, exit banner, UI model, and CLI tests passed again.
Lint for all affected packages reported zero issues, and the CLI build passed.
The development build was also tested interactively by the project maintainer.

## Install

```sh
npm install -g @atlas-coder/atlas-agent@0.15.2
```

Release assets include Windows x64, Linux x64, macOS x64, and macOS arm64.
