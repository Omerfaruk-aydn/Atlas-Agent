# Atlas Agent v0.16.4

## Mobile and remote access

- Expand the phone panel with live screen views, image delivery, secure
  credential cards, and controls for returning a task to Atlas.
- Add funnel integration and improve remote device, application launch,
  monitor selection, screen viewing, and connection handling.
- Extend remote support with live viewing, screen watching, operation
  context, and clearer waiting and power-operation behavior.

## Browser and agent tools

- Add origin-bound, short-lived credential handling and redact supplied
  secrets before saving conversation content or sending it to the model.
- Add browser verification challenge detection and solving actions.
- Improve protected screenshots, browser input, desktop focus, and
  application discovery.
- Add design system, audit, evidence, artifact, and package tools.
- Expand regression coverage for remote operations, credentials, mobile
  views, and browser image contracts.

See `docs/phone-sign-in-and-live-screen.md`, `docs/captcha-solving.md`,
and the remote access guides for setup and behavior details.
