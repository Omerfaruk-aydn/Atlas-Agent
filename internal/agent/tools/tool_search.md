Search tools currently enabled for this agent by name and description. Every
query word must match; results include the actual input schema. Disabled tools
and other agents' tools are not exposed. This tool discovers capabilities; it
does not grant permissions, enable a disabled tool or execute the returned tool.
Use short terms such as "browser", "test", "symbol" or "checkpoint".
When defer_tool_schemas is enabled, discovered allowed schemas become available
on the following model step and remain scoped to the current session.
