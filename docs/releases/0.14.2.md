# Atlas Agent 0.14.2

This release updates model catalogs and provider connections, adds Xiaomi
API and regional Token Plans, and fixes Windows test and shell behavior.

- Catalog coverage: 67 selectable providers and 2,199 provider/model records.
- Separate API and subscription credentials for Xiaomi, Alibaba, Kimi,
  MiniMax, Qiniu and Z.AI; direct Meta and Bedrock OpenAI connections.
- Corrected model identities, hosted pricing, reasoning protocols,
  authentication isolation and tool signature/history handling.
- Portable agent, MCP, Muse, shell and shell configuration tests.
- Cancellable sleep support in the embedded Go coreutils layer.

Validation: the full Go test suite passed, with 96 tested packages;
the CGO-disabled release build and formatting checks passed.
Model access remains subject to provider account, region and plan entitlement.

Install or update:

```sh
npm install -g @atlas-coder/atlas-agent@0.14.2
```

[test fix report](../test-fixes-2026-10-01.md) for source evidence and details.
