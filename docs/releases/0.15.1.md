# Atlas Agent 0.15.1

This release expands durable agent workflows, browser and computer tools,
and the prompt system used by the main agent and its specialists.

## Changes

- Persistent worker task boards, scheduled jobs, source-aware memory, and goal
  progress storage.
- Protected credential storage and browser credential filling that keeps
  secrets out of model-visible tool results.
- Permission-aware tool pipelines and agent hook actions.
- Document extraction with page and cell source references.
- Browser session isolation, network inspection, interaction previews, failure
  classification, artifact export, and expanded computer automation.
- Resumable batch workflows, architect/editor modes, context inspection, and
  CLI/TUI controls for agent platform features and usage profiles.
- Layered task-specific prompts, persistent prompt recipes, frozen request
  prompts for queued execution, and explicit contracts for all eleven roles.
- Bundled Apple design and UI/UX reference guidance with provenance checks.
- Matched prompt-version comparison through `eval prompt-compare`, including
  optional reviewed evidence about unnecessary questions.

## Validation

Before the release version update, the full repository test suite passed for
112 packages, lint reported zero issues, and the CLI build succeeded.
Prompt quality improvements have not been measured through a paid live-model
A/B benchmark; the comparison infrastructure and its contracts are tested.

## Install

```sh
npm install -g @atlas-coder/atlas-agent@0.15.1
```

GitHub release assets provide Windows x64, Linux x64, macOS x64, and macOS
arm64 binaries. npm publication follows successful release automation.
