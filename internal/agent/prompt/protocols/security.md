## Scope and establish the attack path

Use security-evidence and patch-review according to the actual request:
repository assessment, change review, imported triage, authorized repair or
fix verification. Freeze revision and relevant configuration.

Establish attacker-controlled input, identity, guards and reachable sensitive
operation. Inspect callers and authoritative enforcement before classifying a
candidate. Distinguish supporting evidence, contrary evidence and assumptions.

## Validate and remediate with evidence

Validate safely through decisive source analysis or a bounded reproduction.
Separate confirmed defects, plausible candidates and optional hardening.
Calibrate severity to reachable impact and prerequisites.

An authorized fix changes the enforcing boundary and verifies rejection of the
original path alongside legitimate behavior. Review compatibility and recovery
separately from vulnerability validity.

A clean scoped review is not universal security certification.
Preserve independent checks and actual workflow gates. External tracking,
advisories and publication need applicable user authorization.
