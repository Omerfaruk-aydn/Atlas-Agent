# Atlas Agent 0.15.3

Offline microphone dictation, clipboard attachments and timestamped video
inspection now work through the terminal composer and agent tools.

## Changes

- Ctrl+K starts native Windows microphone recording; press it again to insert
  the local transcript at the cursor. Esc cancels, drafts are preserved and
  transcripts are never submitted automatically.
- Vosk recognizes Turkish, English, Italian and French offline on Windows x64.
  `/language` selects the speech model unless dictation language is configured
  separately. No transcription API, Whisper or Python installation is needed.
- Windows npm/PowerShell installations download pinned official Vosk models
  and runtime, verify archive SHA256 hashes and stage files before installation.
  `voice install` retries setup; `voice status` verifies model loading. Downloads
  are approximately 185 MB, with approximately 344 MB of installed assets.
- The original Windows speech engine remains available as an optional backend.
- Ctrl+V pastes clipboard text, images and multiple Explorer files; Ctrl+Alt+V
  provides an alternative when the terminal intercepts Ctrl+V.
- Documents use source-addressable extraction, images require compatible models
  and local videos become references for the agent's permission-checked video
  tool. FFmpeg/FFprobe enable metadata, timestamped frame sampling and offline
  transcription of selected video windows.
- New conversations immediately display submitted text, attachment names and
  localized waiting feedback while uploads or context preparation are running.
  Persisted messages replace previews without duplicates; cancellation, errors
  and session changes clean up pending feedback.
- Windows updates launch the npm CLI through Node directly, supporting Unicode
  paths without passing npm.cmd through a shell.

Recognition accuracy varies; Turkish and Italian sample recordings included
word errors. Arabic speech models are not installed. Microphone recognition is
currently Windows x64 only; other platforms retain the remaining CLI features.

## Validation

The full Go test suite passed, lint reported zero issues and all four platform
builds succeeded. Native transcription was checked with English audio and real
Turkish, French and Italian recordings. A clean Windows installation downloaded
and verified all official speech archives and successfully loaded the Turkish
model. npm installer routing and package contents were checked. The maintainer
also verified microphone dictation and the initial image-prompt feedback fix.

## Install

```sh
npm install -g @atlas-coder/atlas-agent@0.15.3
```

Windows x64, Linux x64, macOS x64 and macOS arm64 binaries are published.
See [media input documentation](../media-input.md) for configuration and limits.
