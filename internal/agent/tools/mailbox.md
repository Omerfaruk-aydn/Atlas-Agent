Read the owner's saved mailbox when a site asks for a code sent by email.

The address and password are already stored. Never ask the owner to paste a password or a mailbox secret into the chat, and never print the secret. This tool returns sender, subject, a short excerpt and any sign-in codes it finds.

Call it when a login page is waiting for an email code. Type the returned code into that page. A mailbox password does not sign in to YouTube, Docs or Drive; those stay on the browser session the owner already opened.

If the mailbox is not saved, say so and stop. The owner adds it in the dot's workspace settings.
