# Atlas Agent v0.15.7

This release expands desktop and browser workflows, introduces interactive
control feedback, and strengthens provider tool compatibility.

## Desktop and browser control

- Add an interactive control island for agent questions and permission requests.
- Display elapsed run time and localized activity status in the control banner.
- Add animated native prompt surfaces, background blur, and notification sounds.
- Keep desktop control ownership separate from user-response waiting states.
- Restore the system cursor and clear control surfaces when a run is stopped.
- Improve physical pointer tracking and preserve browser feedback across tabs.
- Open known task destinations during Chrome startup without a redundant blank tab.

## Workflow execution

- Expand guarded, multi-step desktop and browser pipelines with result bindings.
- Add semantic browser targeting, document guards, condition checks, and tab handling.
- Track completed downloads and validate upload selections.
- Improve desktop application matching, focus recovery, target ledgers, and evidence.
- Add adaptive desktop recipes, batched inputs, and selective observation modes.

## Providers and tool contracts

- Strengthen tool-input validation and provider-specific contract handling.
- Add an OpenCode CLI transport for models accessed through OpenCode.
- Bound Anthropic-compatible schema depth for Meta Muse requests.
- Update Xiaomi reasoning-effort configuration and document its behavior.
- Preserve shell exit outcomes and improve builtin skill address consistency.

## Upgrade

```sh
npm install -g @atlas-coder/atlas-agent@0.15.7
```

Native downloads are available for Windows x64, Linux x64, and macOS x64/arm64.
User interaction with native desktop control remains platform-dependent;
browser fallback behavior is documented in the repository.
