# Atlas Agent 0.15.6

Atlas now ships 22 specialist roles with domain-specific procedures, skill
bindings and evidence-based delivery contracts. The expanded catalog is available
to session modes, delegated agents, CLI inspection and the existing TUI dialogs.

## Changes

- Add product-designer, visual-qa, motion-designer, desktop-operator,
  browser-operator, documents, presentations, data-analyst, template-builder,
  integration-engineer and operations.
- Add sixteen Atlas-authored skills for design systems, visual inspection,
  motion, desktop/browser automation, documents/PDF, presentations, data analysis,
  templates, MCP integration, operations, security, patch review, diagrams,
  research and animated mascot assets.
- Expand all specialist prompts with domain decisions, worked examples,
  failure recovery and completion evidence. Remove fixed role line/byte ceilings
  and the cost-based truncation of selected skill bodies.
- Bind preferred skills to roles after ordinary discovery, user overrides and
  disabled-skill rules. Selected bodies load in full; references remain available
  through focused reads. Skill guidance never grants tools or account access.
- Let the eleven new roles inherit the configured primary model when no dedicated
  assignment exists. Explicit and measured assignments retain precedence;
  invalid explicit assignments fail rather than silently inheriting.
- Extend task routing and prompt protocols for the new domains. Required-tool
  compatibility remains enforced before automatic role selection.
- Preserve prompts, skill bindings, contracts, tool policies and inheritance
  metadata during role editing. An omitted preferred_skills value preserves
  bindings; an explicit empty array clears them.
- Add twenty structural artifact-template recipes with source requirements,
  domain-specific checks and editable-output validation.
- Localize new role descriptions through the existing English, Turkish, German,
  French, Italian and Arabic UI catalog.
- Start confirmed browser click feedback on its first rendered frame so delivery
  delays cannot expire it before display. Repeated owner updates do not replay
  the same feedback; reduced-motion preferences remain respected.

Optional connected Figma, Slack, Calendar and live Excel work requires compatible
tools and the intended account. Local Office authoring, recalculation and visual
rendering use verified installed dependencies. Cached Codex runtimes and account
connections are not bundled. Structural, rendered, fixture and live-service
evidence remain distinct.

See [specialist skills](../specialist-skills.md) and
[role contracts](../agent-roles.md) for the catalog and configuration.

## Validation

The final local repository test run passed. Lint reported zero issues in the
changed packages. Tests cover skill overrides/disablement, complete body loading,
catalog routing, model inheritance, metadata persistence and session/delegation
prompt consistency. These results do not claim live external-account validation.

## Install

```sh
npm install -g @atlas-coder/atlas-agent@0.15.6
```

Release binaries target Windows x64, Linux x64, macOS x64 and macOS arm64.
