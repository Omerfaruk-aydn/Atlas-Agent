# Atlas Agent v0.17.1

## Code map

- Add the `code_map` tool: a ranked map of the project's files, symbols,
  imports, callers and entry points, with queries to find, explain and trace
  paths between parts of the code.
- Report unused assets, missing references and broken links found while
  building the map.
- Route code map requests to `code_map` and keep it available for work beyond
  direct answers.

## Agent and tools

- Hand off to a fresh context after a finished feature when the user asks for
  it, with progress notes as the summary (`work_plan.feature_handoff`).
- Run view, grep, glob and ls as parallel tools, in call order around
  sequential ones.
- Return only new background job output after the first read, and show the
  first error-like line with its context in spilled output.
- Log when a session's turn is canceled.

## Rewind

- Fork the session so it ends with the picked message; nothing runs until the
  user sends something.
- Restore files reliably, including files changed by semantic edit plans and
  forks of forks, and keep the summary pointer and message order.
- The picker starts at the latest message. Late events for copied messages no
  longer duplicate chat items, and copied answers no longer show negative
  durations.

## Providers

- Fix "Corrupted thought signature" errors from Antigravity and Gemini:
  signatures are stored encoded and kept per tool call.

Live acceptance across all providers has not been performed for this release.
