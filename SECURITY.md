# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's
[private vulnerability reporting](https://github.com/Omerfaruk-aydn/Atlas-Agent/security/advisories/new)
for this repository, and include the version, steps to reproduce and the impact.

You can expect an acknowledgement within a few days. Fixes ship in the next release, and the advisory
credits the reporter unless they prefer otherwise.

## Supported versions

Only the latest release receives fixes. Run `atlas-agent update` or `npm i -g @atlas-coder/atlas-agent@latest`.

## Scope notes

Atlas Agent runs commands and edits files on your behalf. Reports about the permission system, the
policy layer, credential handling, the local server and the desktop app's gateway are especially welcome.
