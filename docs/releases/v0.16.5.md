# Atlas Agent v0.16.5

## Agent execution and working memory

- Preserve provider-specific reasoning across compatible retries and fallbacks.
- Add task contracts, working memory, evidence checks, reusable method
  candidates, bounded patch branches and an explicit expertise lifecycle.
- Expose provider capabilities and adapter invocation counts separately from
  stored response steps.
- Add completion review, work-plan checks, request checklists, failure memory,
  environment hints and harness metrics.

## Tools and verification

- Expand authorized tool discovery with detailed schema lookup and shell hints.
- Add pipeline transforms, safer bindings and recovery, file hash checks before
  edits, reference verification and bounded long command output.
- Resize oversized images before model delivery, including images restored
  from conversation history, and preserve native bridge digest metadata while
  keeping credential content redacted.
- Detect unavailable local development servers before browser launch and
  sanitize recorded trace URLs.
- Improve cross-volume file moves in the embedded shell.

## Evaluation and remote support

- Add task benchmark fixtures, failure-corpus replay and independently checked
  delivery selection. Scripted tests do not establish live model success rates.
- Extend remote support with Tailscale Funnel links and connection handling.

## Dependency security

- Update `golang.org/x/net` to v0.60.0 and its required Go support modules,
  fixing the HTTP/2 flow-control issue GO-2026-6612.
- Retain the explicit HTTP/2 connection APIs for support's custom ALPN and
  post-pairing stream upgrade; replacing them with a newly dialed connection
  would change the authenticated protocol.

See `docs/agent-capabilities.md`, `docs/harness.md`, `docs/work-plan.md`,
`docs/task-bench.md` and `docs/remote-support.md` for usage and limits.

Live acceptance across all providers, physical devices and real remote networks
has not been performed for this release.
