Query configured language servers for symbols, definitions, references and
incoming/outgoing calls in Go, JavaScript, TypeScript, Python, Rust or Java.
Specify a literal workspace-relative file. A supported language server must be
configured or discoverable. No lexical approximation is presented as a resolved
dependency. References, definitions and call hierarchy require a symbol name.
Source paths remain scoped
to the workspace. Calls preserve the underlying tool's permission and policy.
