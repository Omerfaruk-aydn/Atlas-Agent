Launch a new agent that has access to the following tools: glob, grep, ls, view. When you are searching for a keyword or file and are not confident that you will find the right match on the first try, use the agent tool to perform the search for you.

Optionally set agent_name to the name of a configured subagent, from the list at the end of this description, to hand the task to it instead of the default agent. A subagent runs with its own instructions appended to the system prompt and, if it names a model role, on that model instead of the session's primary one -- useful for routing a kind of work (e.g. "frontend", "research") to a model suited for it.

If you don't know which subagent fits and don't want to guess, set auto to true (with agent_name left empty) instead: the task is routed to whichever configured subagent's description shares the most words with the prompt. This is a keyword match, not real understanding of the task, so it is worth checking the list of configured subagents at the end of this description first when a specific subagent clearly fits -- auto is for when none obviously does, or there are many candidates and checking each is more overhead than it's worth. Falls back to the default agent when nothing matches; the response reports which subagent (if any) auto picked.
