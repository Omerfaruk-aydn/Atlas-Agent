# Atlas Agent 0.15.5

Computer and browser control now show a persistent agent pointer, an animated
RGB screen border and a compact status banner throughout the agent run,
including waits between tools.

## Changes

- Add a shared graphite pointer with a fine outline, a bounded RGB halo,
  high-DPI rendering and a visible response to confirmed clicks.
- Animate aiming before pointer input. Preserve exact native and fractional
  browser coordinates at the moment of the click, and maintain drag feedback
  across browser tool calls.
- Keep the activity indicator visible through provider waits, and remove it
  when the run finishes, pauses, hands off control or is cancelled.
- Add a compact, localized control banner with a physical Escape shortcut
  that cancels its owning run. Reject page-generated and injected Escape
  events as requests to stop the agent.
- Add animated RGB screen edges with rounded outer corners, smooth smoke
  transitions, 4K geometry and reduced-motion settings.
- Fix banner flicker and pointer visibility by preserving the native overlay
  window order during independent surface updates.
- Hide the ordinary cursor during active control and restore it on cleanup,
  capture suspension or renderer failure. A separate Windows recovery helper
  restores system cursors if the owner exits or stops sending heartbeats.
- Keep overlay windows out of native window discovery and retain clean
  browser HTML extraction. Run-owned visual feedback remains visible during
  observations; standalone operations retain capture suspension.
- Recheck cancellation after pointer presentation before sending native
  clicks. Only successful input produces confirmed click/release feedback.

Tool permissions, hooks and control ownership remain in effect. Windows
supports the desktop overlay; visible browser sessions support the browser
overlay. Settings and verification details are documented in
[agent activity overlay](../agent-activity-overlay.md).

## Install

```sh
npm install -g @atlas-coder/atlas-agent@0.15.5
```

Windows x64, Linux x64, macOS x64 and macOS arm64 binaries are published.
