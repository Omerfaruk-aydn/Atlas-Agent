# Atlas Agent 0.14.3

This release integrates the agent platform, specialist roles and evidence-based delivery workflows.

- Expanded system prompts and specialist contracts, scoped source context and task ownership.
- Persistent source graphs, versioned shared contracts and independent review findings.
- Bounded repair workflows, durable verification journals and checkpoint recovery without automatic command replay.
- Execution policies and project-local environment preparation with explicit installation controls.
- Declarative workflow recipes and source-checked semantic edit previews with crash recovery journals.
- Real browser and native terminal scenarios, retained captures and bounded terminal interpretation.
- Shared revision-checked CLI/server/TUI controls for pause, cancellation and pending task reassignment.
- Embedded design guidance and searchable design data for frontend and terminal work.
- Session resume resolves registered project databases when launched outside the project directory.

Validation: 105 tested Go packages passed, the CGO-disabled Windows build passed,
and seven compiled CLI acceptance checks passed. Real Chrome restart and Windows
ConPTY interaction tests passed. Specialists are mocked in integration fixtures;
live model quality is not certified by these checks.

Linux PTY was cross-compiled but not run locally. Real OCI isolation was not
verified because an explicit local runtime/image fixture was unavailable.
Terminal interpretation is partial, and semantic edit recovery is not a
multi-file OS transaction.

```sh
npm install -g @atlas-coder/atlas-agent@0.14.3
```
