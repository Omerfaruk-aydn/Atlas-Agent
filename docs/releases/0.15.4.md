# Atlas Agent 0.15.4

Desktop automation now combines application preparation, verified input and
fresh observations to reduce unnecessary model round trips on Windows.

## Changes

- Repair native Windows screenshot capture by using a readable DIB section
  and restoring GDI selections before cleanup.
- Enumerate and focus native windows independently of UI Automation, while
  preserving foreground checks before keyboard input.
- Add numbered desktop observations with short-lived, session-bound snapshots
  and fresh target validation before element actions.
- Add read-only computer health checks and clearer recovery guidance.
- Add desktop pipeline recipes for preparing an application, acting and
  observing, and filling and submitting a field with value and focus checks.
- Resolve installed application launch identifiers safely, including Apple
  Music under Turkish Windows locale settings.
- Bound UI Automation traversal and desktop workflows; reject ambiguous,
  expired or changed targets instead of silently reusing them.
- Preserve observation images through pipeline output and add assertion gates
  that stop dependent actions when verification fails.
- Repair Windows hotkey delivery and avoid the Windows command-line length
  limit when loading the automation helper.

These workflows retain tool permissions, hooks and desktop ownership checks.
Individual task duration still depends on the model provider and application
response time. Benchmark results are not a general performance guarantee.

## Install

```sh
npm install -g @atlas-coder/atlas-agent@0.15.4
```

Windows x64, Linux x64, macOS x64 and macOS arm64 binaries are published.
See [desktop control documentation](../desktop-control.md) for usage and limits.
